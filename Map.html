Как это работает

  • Тег <img usemap="#имя"> связывает изображение с картой <map name="имя">.
  • Внутри <map> теги <area> задают активные области.
  • shape="rect" — прямоугольная область, coords="x1,y1,x2,y2".
  • shape="poly" — многоугольная область, coords="x1,y1,x2,y2,x3,y3,...".
  • shape="circle" — круглая область, coords="x,y,r".
  • Атрибут title показывает подсказку при наведении мыши.
  • Атрибут href указывает страницу для перехода.

Как подобрать точные координаты

  1. Откройте город.gif в Paint.
  2. Наведите курсор на угол улицы — внизу слева Paint показывает координаты (например, 180, 100).
  3. Для shape="rect" укажите: coords="x1,y1,x2,y2" (левый верхний и правый нижний угол).
  4. Для shape="poly" укажите все вершины по порядку.
  5. Или используйте онлайн-инструмент: image-map.net — загрузите картинку, нарисуйте области мышкой, скопируйте готовый код.
